Chopstick Catch — catch falling Starship boosters with the Mechazilla tower's chopstick arms. Complete Flight 15: catch 15 boosters to win, dodge satellite debris, build combos, and keep the tower standing. A complete arcade game in vanilla JavaScript + Canvas: no network, no libraries, no build step.

## Run it

Serve the `game/` folder with any static file server, then open `index.html`:

```sh
cd game && python3 -m http.server 8080
```

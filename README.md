Chopstick Catch v2 — catch falling Starship boosters with the Mechazilla tower's chopstick arms. Complete Flight 15 across 3 realms: Launch Pad Dawn, Storm Front, and Night Recovery. Catch 15 boosters per realm, clamp each realm's boss, spend Scrap on 12 upgrades in the Workshop, collect 10 permanent relics in the Vault, finish missions, then survive Endless mode. A complete arcade game in vanilla JavaScript + Canvas: no network, no libraries, no build step. Measured 60.0 FPS at 1920x1080 on an RTX 4060.

## Controls

Move the arms with the MOUSE or the ← → arrow keys. S slows time, P pauses, M mutes, F toggles the FPS meter. Enter starts, R restarts.

## Run it

Serve the `game/` folder with any static file server, then open `index.html`:

```sh
cd game && python3 -m http.server 8080
```
